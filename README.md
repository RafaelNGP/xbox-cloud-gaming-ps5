# ⚠️ Temporary update bridge / Ponte temporária de atualização

**This is NOT the PSBox Cloud Gaming repository.** It exists for a short time **only** so that old installs (v1.6.3 and earlier) can find the v1.6.9 update in-app.

**The official repository is [RafaelNGP/psbox-cloud-gaming](https://github.com/RafaelNGP/psbox-cloud-gaming).** All releases, updates, issues and news are published there only.

Why: the project was renamed from `xbox-cloud-gaming-ps5` to `psbox-cloud-gaming`. Versions up to v1.6.3 still look for updates under the old name and could not follow GitHub's redirect ([issue #409](https://github.com/RafaelNGP/psbox-cloud-gaming/issues/409)). This bridge offers them the official, signed v1.6.9 package, identical to the one in the official repository. After updating, the app looks for updates in the official repository only.

The bridge release removes itself automatically on **2026-12-25**. If your app still has v1.6.3 or older after that, download v1.6.9 or later from the [official releases](https://github.com/RafaelNGP/psbox-cloud-gaming/releases).
